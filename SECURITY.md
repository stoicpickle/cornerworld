# Security policy

## Supported version

Security fixes are currently made against the latest 1.x release and `main`.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use the
project's private [security-advisory form](https://github.com/stoicpickle/cornerworld/security/advisories/new).

Include the affected revision, reproduction steps, impact, and any suggested
mitigation. Please avoid accessing data or systems that are not yours.

Cornerworld 1.0 is a local, source-built macOS application. It has no network
service, account system, telemetry, updater, or persistent save format.
